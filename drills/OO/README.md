# OODrills

Ce drill vous remettra rapidement dans les doigts et dans la tête certains éléments basiques de la programmation orientée objet en C#.

Tout ce que vous avez à faire, c'est ouvrir la solution, exécuter les tests, constater les dégâts, les analyser, et travailler jusqu'à ce que tous les tests passent avec succès.

Bon travail!
