# Annexe UMDD

Terrain de la [séquence finale](../grille.md) : la ville de [UMDD](../../activites/fil-rouge/umdd/README.md), avec ses services partagés par la classe.

- Piste *feature* : une fonctionnalité à ajouter sur la ville.
- Piste *code* : un code défectueux à réparer.
- Banque d'énoncés : voir [la grille](../grille.md#banque-d-enonces) ; remplacer « un service » par les services de la ville (banque, coopérative, annuaire) pour les histoires.
